# Bootstrap & Setup

Quick bootstrap command to set up the React frontend development environment:

1. **Dependencies**: Install Node.js packages
2. **Environment**: Verify `.env` configuration
3. **Build Check**: Ensure the app compiles without errors
4. **Lint Check**: Run ESLint to verify code quality
5. **Dev Server**: Start the Vite dev server

## Steps
- Run `npm install` to install dependencies
- Verify `.env` has `VITE_API_URL` set
- Run `npm run build` to verify compilation
- Run `npm run lint` to check for issues
- Start `npm run dev` for development
- Report status of each step
